# OPS — AI 팀 운영·인프라·실험

## 범위
특정 제품이 아닌 일: AI 팀 자체의 운영과 개선, VM 관리, 도구·기술 조사, 실험성 작업.

## 환경
- VM: OCI Always Free (Ubuntu, ARM). 비용이 생기는 변경은 하지 않는다.
- 봇: leader · dev · research (봇마다 다른 리눅스 사용자 bot-<이름>), 디스패처가 Jira(`TEAM`) 기준으로 작업 실행
- 연습용 레포: dev 의 `~/projects/sandbox` (마음껏 실험해도 됨)

## 제약
- 봇에게는 sudo 가 없다. 관리자 권한이 필요하면 보고서의 `## 관리자 명령 요청` 에 명령과 이유를 적는다(승인형).
- 토큰·키·`.env` 내용은 출력하거나 보고서에 넣지 않는다.
- 삭제·재부팅·방화벽/네트워크 변경 등 되돌리기 어려운 작업은 하지 않고 제안만 한다.
- 디스패처·설정(`/opt/ai-team`, `/etc/ai-team`)은 root 소유다. 개선안은 코드 조각과 이유로 제안한다.
